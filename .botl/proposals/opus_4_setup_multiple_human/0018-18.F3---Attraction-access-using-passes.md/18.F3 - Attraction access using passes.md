# F3-C08 — Attraction access using passes

"Objective
Extend ATTRACTION ENTER to use SpeedPasses and Special Passes while respecting atomicity, attraction type, and consumption rules.
Description
At GENERAL and INDIVIDUAL attractions, an individual ticket may enter normally or request use of a SpeedPass with the SPEED option.
GENERAL and GROUP attractions also permit group ticket entry with SPEED. In that case, every individual ticket in the composition must have at least one unused SpeedPass. If any member lacks one or any other access condition fails, no user enters and no SpeedPass is consumed.
SPECIAL attractions permit individual entries only. The system automatically locates the Special Pass associated with the ticket, checks that it has not been consumed, and marks it as consumed only after successful entry. The SPEED option is not accepted at these attractions.
Acceptance criteria
• 
ATTRACTION ENTER;<atraccion>;<entrada> preserves normal entry.
• 
ATTRACTION ENTER;<atraccion>;<entrada>;SPEED requests SpeedPass use.
• 
Individual entry with SPEED consumes exactly one unused SpeedPass.
• 
Group entry with SPEED consumes one for each member.
• 
Group entry with SPEED is atomic.
• 
A failed entry does not consume passes.
• 
A SPECIAL attraction automatically consumes its Special Pass.
• 
The output reports when a Special Pass or SpeedPass is consumed.
• 
SPEED is rejected at SPECIAL attractions.
Mandatory commit
[F3-C08] Extend attraction access and pass consumption"
