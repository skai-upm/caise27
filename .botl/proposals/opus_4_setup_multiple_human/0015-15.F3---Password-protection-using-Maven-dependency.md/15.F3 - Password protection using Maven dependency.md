# F3-C05 — Password protection using Maven dependency

"Objective
Prevent storage of plaintext passwords and add an external library through Maven.
Description
A simple Maven dependency will be added to protect passwords using BCrypt. Passwords must be stored as hashes, and operations requiring authentication must verify the supplied password against the stored value.
The password format validation defined in E1 still applies before generating the hash.
Acceptance criteria
• 
The BCrypt dependency is declared in pom.xml.
• 
New passwords are not stored in plaintext.
• 
USER DELETE correctly validates the password.
• 
USER UPDATE validates the current password.
• 
Changing a password persists a new hash.
• 
The password format rules from E1 continue to apply.
Mandatory commit
[F3-C05] Secure stored user passwords"
