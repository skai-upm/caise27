# Change 1 — Bootstrap a Java 21 Maven application

**Suggested change ID:** `bootstrap-java21-maven-project`

## Why

Establish a reproducible Java application skeleton and test infrastructure before introducing any amusement-park functionality.

## What changes

- Create the project with `org.apache.maven.archetypes:maven-archetype-quickstart` using Maven and JDK 21.
- Keep the standard Maven Quickstart project layout, the executable entry-point class, and the generated/basic test layout.
- Configure the application so Maven can create an executable JAR with its main class.
- Confirm `mvn test` succeeds on JDK 21.

## Scope and constraints

**In scope:** build files, standard `src/main/java` and `src/test/java` structure, application entry point, test setup, executable JAR configuration. **Out of scope:** user management, command implementation, domain models, tickets, groups, attractions, and added nonessential infrastructure.

**Capabilities:** new `application-bootstrap` (Maven toolchain, standard structure, entry point, executable packaging, tests).

## Verifiable acceptance scenarios

1. **Fresh build:** Given the project has been checked out and JDK 21/Maven are available, when `mvn test` is run, then the project compiles and the tests pass.
2. **Executable packaging:** Given a successful Maven build, when the project is packaged, then an executable JAR is produced with a configured entry point and starts without a missing-main-manifest error.
3. **Standard layout:** Given the repository, when its directory structure is reviewed, then the Maven Quickstart layout and basic testing structure are present.
4. **No premature features:** Given the completed change, when its production code is reviewed, then amusement-park business functionality has not been added.

## Design and task guidance

Document the Java 21 compiler configuration, Maven plugins required for executable packaging, and location of the entry point. Define verification tasks for a clean test build and packaged JAR. Do not require an application-specific command protocol in this change.

## Appendix — Original proposal text (verbatim)

I want to create a Java application with Maven using JDK 21.
The project must be generated using the archetype:
org.apache.maven.archetypes:maven-archetype-quickstart
This is the first step of the project and will be carried out in the laboratory.
It must be possible to generate an executable JAR using the main class.

Requirements:
- The project must compile with JDK 21.
- It must use Maven.
- It must retain the standard structure generated by the Maven Quickstart archetype.
- It must include an executable main class.
- It must include the basic testing structure.
- The project must compile successfully with mvn test.
- No application-domain functionality should be added yet.
