## Authoritative detailed requirements (verbatim source excerpts)

## 14. UML representation

A class diagram representing the final Phase 2 design must be submitted together with the code. The diagram must be created using PlantUML. The repository must contain the source file:

```text
uml/model.puml
```

The PlantUML diagram must represent the model structure and relationships among its elements. Methods and constructors need not be included. Only relevant attributes and, where appropriate to the design, the following must be shown:

- classes and interfaces;
- relevant enumerations;
- inheritance;
- interface implementations;
- associations;
- compositions;
- relationship directions;
- multiplicities.

In particular, the ticket hierarchy, composition between a group ticket and its individual tickets, and the relationships among users, groups, tickets, and attractions must be represented correctly. The diagram must correspond to the code actually submitted. Evaluation will consider not only its appearance but also its consistency with the implementation.
