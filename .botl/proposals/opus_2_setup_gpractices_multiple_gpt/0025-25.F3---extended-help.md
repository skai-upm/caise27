## Authoritative detailed requirements (verbatim source excerpts)

## 7. Extended help

The HELP command will remain available and must continue to display the syntax of the commands recognized by the application. The following will also be added:

```text
HELP EXTENDED
```

This version must display a brief explanation of each command’s purpose alongside its syntax. The class responsible for generating help text must receive, through dependency injection, the behavior used to build that output. The design must be prepared to incorporate new ways of generating help in future extensions, without coupling these variants to the general logic for reading and executing commands.
