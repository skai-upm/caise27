## Authoritative detailed requirements (verbatim source excerpts)

## 8. Password protection

User passwords must no longer be stored in plain text. The application must add, via Maven, a basic library for applying BCrypt to passwords. For example, the jBCrypt dependency may be used:

```text
<dependency>
<groupId>org.mindrot</groupId>
<artifactId>jbcrypt</artifactId>
<version>0.4</version>
</dependency>
```

The password validation rules established in Delivery 1 must be applied before a new password is stored. The persistence file must not contain the original password; only its BCrypt-protected value may be stored. Operations that require password verification, such as USER DELETE or USER UPDATE, must validate the entered password against the stored value using the added library. When a password is changed, a new protected value must be generated and persisted. Automatic migration of user files generated by earlier versions of the assignment is not required.
