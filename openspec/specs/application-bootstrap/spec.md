# application-bootstrap Specification

## Purpose
Provides the buildable Java 21 Maven application skeleton — standard Quickstart layout, executable entry point, executable JAR packaging and baseline tests — on which all later amusement-park features are built.

## Requirements

### Requirement: Maven build targeting JDK 21
The project SHALL be a Maven project whose sources compile for Java release 21, and `mvn test` SHALL compile the project and pass its tests on JDK 21.

#### Scenario: Fresh test build succeeds
- **GIVEN** a fresh checkout with JDK 21 (or newer, targeting release 21) and Maven available
- **WHEN** `mvn test` is run from the repository root
- **THEN** the build compiles main and test sources and reports `BUILD SUCCESS` with zero test failures

#### Scenario: Compiled bytecode targets Java 21
- **GIVEN** a successful build
- **WHEN** the compiled main class file version is inspected
- **THEN** it corresponds to Java 21 (class file major version 65)

### Requirement: Maven Quickstart standard layout
The project SHALL keep the directory structure generated by the `org.apache.maven.archetypes:maven-archetype-quickstart` archetype: a root `pom.xml`, production sources under `src/main/java` and test sources under `src/test/java`.

#### Scenario: Standard layout present
- **WHEN** the repository structure is reviewed
- **THEN** `pom.xml`, `src/main/java/` containing the entry-point class and `src/test/java/` containing at least one test class are present

### Requirement: Executable entry point
The project SHALL contain one executable main class exposing `public static void main(String[] args)`, which starts and exits normally when invoked.

#### Scenario: Entry point runs
- **WHEN** the main class is executed with no arguments
- **THEN** the process terminates with exit status 0

### Requirement: Executable JAR packaging
Packaging the project with Maven SHALL produce a JAR whose manifest declares the entry-point class as `Main-Class`, so it can be launched with `java -jar`.

#### Scenario: Packaged JAR starts
- **GIVEN** `mvn package` completed successfully
- **WHEN** `java -jar` is run on the produced JAR
- **THEN** the application starts without a "no main manifest attribute" error and exits with status 0

#### Scenario: Manifest declares main class
- **WHEN** the produced JAR's `META-INF/MANIFEST.MF` is inspected
- **THEN** it contains a `Main-Class` entry naming the entry-point class
