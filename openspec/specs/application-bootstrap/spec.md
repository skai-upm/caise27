# application-bootstrap Specification

## Purpose
Defines the build toolchain, project structure, executable entry point and test infrastructure that every later amusement-park feature builds upon.

## Requirements

### Requirement: Java 21 Maven build
The project SHALL be built with Maven and SHALL compile its sources targeting Java 21.

#### Scenario: Fresh test build succeeds
- **GIVEN** a fresh checkout with JDK 21 and Maven available
- **WHEN** `mvn test` is run
- **THEN** the project compiles and all tests pass

#### Scenario: Bytecode targets Java 21
- **GIVEN** a successful build
- **WHEN** a compiled main class file is inspected
- **THEN** its class-file major version corresponds to Java 21 (65)

### Requirement: Standard Quickstart project layout
The project SHALL retain the standard layout generated by `org.apache.maven.archetypes:maven-archetype-quickstart`, with a root `pom.xml`, production sources under `src/main/java` and tests under `src/test/java`.

#### Scenario: Layout review
- **WHEN** the repository structure is reviewed
- **THEN** `pom.xml`, `src/main/java` and `src/test/java` exist and production classes are declared in a named package

### Requirement: Executable entry point
The project SHALL contain an executable main class that starts the application.

#### Scenario: Entry point runs
- **WHEN** the main class is executed
- **THEN** the process terminates normally with exit status 0

### Requirement: Executable JAR packaging
Packaging the project SHALL produce a JAR whose manifest declares the main class, so it can be launched with `java -jar`.

#### Scenario: Packaged JAR starts
- **GIVEN** a successful `mvn package`
- **WHEN** `java -jar` is run on the produced JAR
- **THEN** the application starts without a "no main manifest attribute" error and exits with status 0

### Requirement: Basic test infrastructure
The project SHALL include a test source tree with at least one automated test that Maven executes during the `test` phase.

#### Scenario: Tests are discovered
- **WHEN** `mvn test` is run
- **THEN** Maven reports at least one executed test and zero failures

### Requirement: No domain functionality in bootstrap
The bootstrap SHALL NOT contain amusement-park business functionality such as users, commands, tickets, groups or attractions.

#### Scenario: Production code review
- **WHEN** the production sources are reviewed
- **THEN** only the entry-point class exists and it contains no domain logic
