# project-build Specification

## Purpose

Defines how the amusement-park application is built, tested and packaged so that it can be compiled with Maven on JDK 21 and run outside an IDE.

## Requirements

### Requirement: Maven Quickstart project on JDK 21
The project SHALL be a Maven project targeting Java 21 that retains the standard directory structure generated by `org.apache.maven.archetypes:maven-archetype-quickstart` (`src/main/java`, `src/test/java`, `pom.xml`). It SHALL use only the Java standard library at runtime.

#### Scenario: Standard layout is present
- **WHEN** the repository is inspected
- **THEN** a `pom.xml` declaring Java 21 compilation exists along with `src/main/java` and `src/test/java` source trees

#### Scenario: No runtime third-party dependencies
- **WHEN** the declared Maven dependencies are inspected
- **THEN** every third-party dependency is limited to the `test` scope

### Requirement: Tests run with mvn test
The project SHALL include a basic automated test structure, and `mvn test` SHALL compile the project and pass all tests.

#### Scenario: Clean project build
- **WHEN** `mvn test` runs in a JDK 21 environment
- **THEN** the project compiles and all tests pass

### Requirement: Executable JAR
The build SHALL produce an executable JAR whose manifest names the application's main class, so the application can be launched with `java -jar` without an IDE.

#### Scenario: Launching the packaged application
- **WHEN** `mvn package` is run and the resulting JAR is launched with `java -jar`
- **THEN** the application starts and enters its command-execution path
