# project-build Specification

## Purpose

Defines how the amusement-park application is built, tested, and packaged so it can run independently of any IDE on a Java 21 runtime.

## Requirements

### Requirement: Java 21 Maven Quickstart project
The project SHALL be a Maven project targeting Java 21 that keeps the standard directory structure generated by `org.apache.maven.archetypes:maven-archetype-quickstart` (`src/main/java`, `src/test/java`, `pom.xml`) and uses only the Java standard library at runtime.

#### Scenario: Project compiles for Java 21
- **GIVEN** a checkout of the project in a JDK 21 compatible environment
- **WHEN** the project is compiled with Maven
- **THEN** the sources compile with Java 21 as the target release

#### Scenario: No third-party runtime dependencies
- **WHEN** the project's dependencies are inspected
- **THEN** only test-scoped dependencies are declared

### Requirement: Automated tests run with mvn test
The project SHALL contain a basic test structure and `mvn test` SHALL compile the project and pass all of its tests.

#### Scenario: Clean project build
- **GIVEN** the project has been checked out in a compatible JDK 21 environment
- **WHEN** `mvn test` runs
- **THEN** the project compiles and all tests pass

### Requirement: Executable JAR
The build SHALL produce an executable JAR whose manifest entry point is the application's main class, so that `java -jar <jar>` starts the application.

#### Scenario: Executable entry point
- **GIVEN** the packaged application JAR
- **WHEN** it is launched with `java -jar`
- **THEN** the application starts its command-execution path without requiring an IDE or an explicit classpath
