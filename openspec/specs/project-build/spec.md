# project-build Specification

## Purpose

Defines how the amusement-park application is built, tested, and packaged as a Java 21 Maven project that can run outside an IDE.

## Requirements

### Requirement: Maven quickstart project on JDK 21
The project SHALL be a Maven project that retains the standard directory structure generated by the `org.apache.maven.archetypes:maven-archetype-quickstart` archetype and SHALL compile with JDK 21 (Java release 21).

#### Scenario: Standard structure is present
- **WHEN** the repository is inspected
- **THEN** it contains a `pom.xml`, main sources under `src/main/java` and test sources under `src/test/java`

#### Scenario: Compiles for Java 21
- **WHEN** the project is compiled with a JDK 21 toolchain
- **THEN** compilation succeeds targeting Java release 21

### Requirement: Tests run with mvn test
The project SHALL include an application entry-point class and a basic automated test structure, and `mvn test` SHALL complete successfully.

#### Scenario: Clean project build
- **WHEN** `mvn test` runs on a checkout in a JDK 21 environment
- **THEN** the project compiles and all tests pass

### Requirement: Executable JAR
The build (`mvn package`) SHALL produce the executable JAR `target/parque.jar`, which includes the runtime dependencies and whose manifest entry point starts the application, so that it can be launched with `java -jar` without an IDE.

#### Scenario: Launch packaged application
- **WHEN** the project is packaged and the resulting JAR is launched with `java -jar`
- **THEN** the application starts and enters its command-execution path

### Requirement: Standard library only at runtime
The application SHALL use only the Java standard library and a BCrypt password-hashing library at runtime; no frameworks, databases, or other third-party runtime libraries SHALL be added.

#### Scenario: No runtime dependencies
- **WHEN** the project's declared dependencies are inspected
- **THEN** the only non-test dependency is the BCrypt library
