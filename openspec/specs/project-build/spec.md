# project-build Specification

## Purpose
Defines how the amusement-park application is built, tested and packaged as an executable Java 21 Maven project.

## Requirements

### Requirement: Maven project on Java 21
The project SHALL be a Maven project that compiles its sources for the Java 21 platform and retains the standard directory layout generated by `maven-archetype-quickstart`.

#### Scenario: Build compiles for Java 21
- **WHEN** a developer runs `mvn compile` with a JDK supporting release 21
- **THEN** the build succeeds and the produced classes target Java 21

#### Scenario: Standard archetype layout is present
- **WHEN** the repository is inspected
- **THEN** it contains `pom.xml`, a main source tree under `src/main/java` and a test source tree under `src/test/java`

### Requirement: Test structure runs with mvn test
The project SHALL include a basic unit-test structure that is executed by `mvn test`, and the build SHALL pass.

#### Scenario: Tests pass
- **WHEN** a developer runs `mvn test`
- **THEN** the test phase executes the existing unit tests and the build reports success

### Requirement: Executable JAR
Packaging the project SHALL produce a JAR whose manifest declares the application's main class, so it can be run with `java -jar`.

#### Scenario: Run the packaged JAR
- **WHEN** a developer runs `mvn package` and then `java -jar` on the produced JAR
- **THEN** the application's main class runs and terminates normally

### Requirement: No domain functionality yet
The initial project SHALL NOT contain application-domain functionality; the main class only provides a minimal entry point.

#### Scenario: Minimal entry point
- **WHEN** the application is run
- **THEN** it prints a simple start-up message and exits without performing any domain operation
