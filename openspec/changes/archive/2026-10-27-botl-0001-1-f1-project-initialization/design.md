# Design

## Context

The repository currently contains only OpenSpec scaffolding, a README and a Maven-oriented `.gitignore`. See proposal.md for motivation.

## Goals / Non-Goals

**Goals:**
- Reproduce the output of `maven-archetype-quickstart` (current archetype version uses JUnit Jupiter) at the repository root.
- Target Java 21 independent of the JDK version installed (newer JDKs compile with `--release 21`).

**Non-Goals:**
- Executable JAR configuration (milestone F0-C02).
- Any domain or command-processing code.

## Decisions

- **Project at repository root** rather than in a sub-folder: later milestones run `mvn package` from the repository and the `.gitignore` already targets root `target/`.
- **`maven.compiler.release=21`** instead of `source`/`target`: `release` also checks API usage against JDK 21, which is the stronger guarantee.
- **JUnit Jupiter 5 via BOM**, as generated by archetype 1.5; avoids the legacy JUnit 4 dependency.
- **Coordinates** `es.upm:amusement-park:1.0-SNAPSHOT`, package `es.upm.amusementpark` — placeholders, since the source names none.
- **Pinned plugin versions** (compiler, surefire, jar, etc.) as the archetype does, for reproducible builds.

## Risks / Trade-offs

- [Build machine has a JDK newer than 21] → `release 21` guarantees JDK 21 bytecode and API compatibility.
- [Chosen coordinates differ from what an evaluator expects] → flagged in proposal; trivial to rename later.
