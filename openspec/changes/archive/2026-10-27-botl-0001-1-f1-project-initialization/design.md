# Design

## Context

The repository currently contains only OpenSpec scaffolding (see proposal.md - Why). The source milestone mandates JDK 21, Maven and the `apache-maven-quickstart` archetype; it does not fix a groupId, artifactId or root package (later milestones use the placeholder `target/nombre-aplicacion.jar`).

## Goals / Non-Goals

**Goals:**
- Produce the exact layout generated by `maven-archetype-quickstart` at the repository root.
- Compile for Java 21 and keep `mvn package` green.

**Non-Goals:**
- Executable JAR / entry point configuration (milestone F0-C02).
- Any domain, command or persistence behavior.

## Decisions

- **Generate with the archetype rather than hand-writing files.** Run `mvn archetype:generate -DarchetypeGroupId=org.apache.maven.archetypes -DarchetypeArtifactId=maven-archetype-quickstart -DarchetypeVersion=1.5` non-interactively, then move the generated project to the repository root. Alternative (hand-written pom) rejected: the source explicitly requires the archetype.
- **Coordinates (assumption, flagged):** `groupId=es.upm.amusementpark`, `artifactId=amusement-park`, `version=1.0-SNAPSHOT`, root package `es.upm.amusementpark`. The source does not specify them; `nombre-aplicacion` in later milestones is a placeholder for the application name.
- **JDK level:** set `maven.compiler.release` to `21` (archetype 1.5 uses the `release` property). `release` (not `source/target`) guarantees the JDK 21 API is used even when Maven runs on a newer JDK.
- **Mandatory commit:** the exact message `[F0-C01] Initialize Maven project with JDK 21` is produced by the batch Git step after the change is verified and archived, so the commit contains the verified project. It is not a code task.

## Risks / Trade-offs

- [Archetype download requires network access to Maven Central] → If unavailable, stop and report rather than hand-crafting an equivalent.
- [The local Maven runs on a JDK newer than 21] → `maven.compiler.release=21` restricts compilation to the Java 21 API, so the build stays JDK 21–compatible.
