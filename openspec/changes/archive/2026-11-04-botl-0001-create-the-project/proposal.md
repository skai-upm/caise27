# Proposal

## Why

The repository has no application code yet. A reproducible Java 21 / Maven skeleton with a working test setup and executable packaging is needed before any amusement-park functionality can be built on top of it.

## What Changes

- Generate a Maven project from `org.apache.maven.archetypes:maven-archetype-quickstart` at the repository root.
- Keep the standard Quickstart layout (`pom.xml`, `src/main/java`, `src/test/java`), the generated entry-point class and the generated basic test.
- Configure compilation for Java 21.
- Configure packaging so `mvn package` produces a JAR whose manifest declares the main class, runnable with `java -jar`.
- Verify `mvn test` succeeds.
- No amusement-park domain functionality is added.

## Capabilities

### New Capabilities
- `application-bootstrap`: Build toolchain (Maven, Java 21), standard project layout, executable entry point, executable JAR packaging and basic test infrastructure.

### Modified Capabilities
_None._

## Impact

- New files: `pom.xml`, `src/main/java/**/App.java`, `src/test/java/**/AppTest.java`.
- Build dependency: JUnit (test scope only), as generated by the archetype.
- Every later change builds on this skeleton.
