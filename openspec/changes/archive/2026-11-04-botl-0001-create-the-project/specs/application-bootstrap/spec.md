# Spec Delta

## Purpose

Defines the build toolchain, project layout, executable entry point and test infrastructure on which the amusement-park application is built.

## ADDED Requirements

### Requirement: Maven build targeting Java 21
The project SHALL be built with Maven and SHALL compile its sources for the Java 21 platform.

#### Scenario: Fresh build compiles and tests pass
- **WHEN** the project is checked out and `mvn test` is run with Maven and a JDK able to target Java 21
- **THEN** the build compiles all sources and finishes with all tests passing

#### Scenario: Compiled classes target Java 21
- **WHEN** the project is compiled
- **THEN** the produced class files have the Java 21 class-file version (major version 65)

### Requirement: Standard Maven Quickstart layout
The project SHALL keep the directory layout generated by `org.apache.maven.archetypes:maven-archetype-quickstart`: a root `pom.xml`, production sources under `src/main/java` and test sources under `src/test/java`.

#### Scenario: Layout review
- **WHEN** the repository structure is reviewed
- **THEN** `pom.xml`, `src/main/java` containing the entry-point class and `src/test/java` containing at least one test class are present

### Requirement: Executable JAR
Packaging the project SHALL produce a JAR whose manifest declares the application entry-point class, so that it can be started with `java -jar`.

#### Scenario: Run packaged JAR
- **WHEN** `mvn package` succeeds and the produced JAR is started with `java -jar`
- **THEN** the application starts and exits normally without a "no main manifest attribute" error

### Requirement: Basic test infrastructure
The project SHALL include a test framework dependency and at least one automated test that runs as part of the Maven `test` phase.

#### Scenario: Tests are executed by Maven
- **WHEN** `mvn test` is run
- **THEN** the Maven test report shows at least one test executed and zero failures

### Requirement: No domain functionality in the bootstrap
The bootstrap SHALL NOT contain amusement-park business functionality such as users, commands, tickets, groups or attractions.

#### Scenario: Production code review
- **WHEN** the production sources are reviewed after this change
- **THEN** they contain only the generated entry-point class and no domain model or command handling
