# Spec Delta

## MODIFIED Requirements

### Requirement: Java 21 Maven Quickstart project
The project SHALL be a Maven project that compiles for Java 21 and retains the standard directory structure generated by `org.apache.maven.archetypes:maven-archetype-quickstart` (`src/main/java`, `src/test/java`, `pom.xml`). At runtime it SHALL use only the Java standard library plus the BCrypt library required for password protection.

#### Scenario: Clean project build
- **GIVEN** the project is checked out in an environment with a JDK capable of targeting Java 21
- **WHEN** `mvn test` runs
- **THEN** the project compiles and all its tests pass

#### Scenario: No runtime third-party dependencies
- **WHEN** the project's declared dependencies are inspected
- **THEN** every third-party dependency is in the `test` scope except the BCrypt library

### Requirement: Executable JAR
The build SHALL produce a JAR whose manifest declares the application entry point and that contains the runtime dependencies, so that `java -jar <jar>` starts the application without an IDE.

#### Scenario: Launch packaged application
- **GIVEN** the project has been packaged with `mvn package`
- **WHEN** the produced JAR is launched with `java -jar`
- **THEN** the application starts and enters its command-execution path
