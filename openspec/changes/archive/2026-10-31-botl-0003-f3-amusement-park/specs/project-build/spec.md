# Spec Delta

## REMOVED Requirements

### Requirement: Maven Quickstart project on JDK 21
**Reason**: Delivery 3 requires a BCrypt Maven dependency at runtime, which contradicts the "only the Java standard library at runtime" rule of this requirement.
**Migration**: Replaced by "Maven Quickstart project with BCrypt runtime dependency", which keeps the same layout and Java 21 rules and allows exactly the BCrypt library at runtime.

## ADDED Requirements

### Requirement: Maven Quickstart project with BCrypt runtime dependency
The project SHALL be a Maven project targeting Java 21 that retains the standard directory structure generated by `org.apache.maven.archetypes:maven-archetype-quickstart` (`src/main/java`, `src/test/java`, `pom.xml`). At runtime it SHALL use only the Java standard library plus the BCrypt password-hashing library.

#### Scenario: Standard layout is present
- **WHEN** the repository is inspected
- **THEN** a `pom.xml` declaring Java 21 compilation exists along with `src/main/java` and `src/test/java` source trees

#### Scenario: Only the BCrypt runtime dependency
- **WHEN** the declared Maven dependencies are inspected
- **THEN** the only dependency outside the `test` scope is the BCrypt library

## MODIFIED Requirements

### Requirement: Executable JAR
The build SHALL produce an executable JAR whose manifest names the application's main class and which contains the runtime dependencies, so the application can be launched with `java -jar` without an IDE.

#### Scenario: Launching the packaged application
- **WHEN** `mvn package` is run and the resulting JAR is launched with `java -jar`
- **THEN** the application starts and enters its command-execution path
