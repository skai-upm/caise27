# Design

## Context

21 production classes in `es.upm.parque`. Cross-cutting details that block a clean split: `TicketRepository` (persistence) calls `MainController.parseDate/formatDate/formatPrice` (a controller); `GroupTicket.addTicket/removeTicket` are package-private but used by `TicketRepository` and `TicketManager`; `TextFiles` is package-private and used only by repositories; tests rely on package-private members (`CommandProcessor.COMMAND_SYNTAX`, `App.createProcessor`) and on the shared `TestPark` fixture.

## Goals / Non-Goals

**Goals:**
- Layered packages with dependencies presentation → business ← persistence model use, and business controllers → persistence repositories (classic three-layer: controllers load/save through repositories).
- A behaviour-preserving move: the existing 167 tests keep passing with only package/import/name updates.

**Non-Goals:**
- Singleton/dependency-injection changes (next change), new behaviour.

## Decisions

- **Package map**:
  - `es.upm.parque`: `App` (composition root and JAR main class).
  - `presentation`: `CommandProcessor`, `ExecutionOptions`.
  - `business`: `ParkException`; `business.model`: `User`, `UserField`, `Group`, `Ticket`, `IndividualTicket`, `GroupTicket`, `Attraction`, `Values`; `business.controller`: `MainController`, `UserController`, `GroupController`, `TicketController`, `AttractionController`; `business.validation`: `UserValidator`.
  - `persistence`: `UserRepository`, `GroupRepository`, `TicketRepository`, `AttractionRepository`, `TextFiles`, `DataDirectory`.
- **Managers renamed to controllers** (`UserManager` → `UserController`, …; fields `userManager` → `userController`, …): the delivery describes the business layer in terms of controllers, and the next change makes them Singletons.
- **`Values`** (model): `parseDate`, `formatDate`, `parsePrice`, `formatPrice` moved from `MainController`, used by controllers, presentation and persistence; `MainController` keeps only the system date and price state.
- **Visibility**: `GroupTicket.addTicket/removeTicket` become public (used across layers); `TextFiles` stays package-private inside `persistence`; `CommandProcessor.COMMAND_SYNTAX` and the syntax constants stay package-private (their tests move to `presentation` too); `App.createProcessor` stays package-private (its test lives in `es.upm.parque`).
- **Tests** move to mirrored packages; `TestPark` becomes a public fixture in `es.upm.parque` with public fields. New `LayeredArchitectureTest` scans `src/main/java` sources and asserts: every file declares a package; presentation and model sources do not import `es.upm.parque.persistence` or `java.nio.file`; the three layer packages exist.
- **Mechanics**: files moved with `git mv`; package declarations and explicit imports regenerated by a script from the class→package map (no wildcard imports).

## Risks / Trade-offs

- [Large diff from moving files] → Pure moves are tracked as renames by git; behaviour is guarded by the unchanged test suite plus an end-to-end run.
