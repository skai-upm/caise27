# Spec Delta

## ADDED Requirements

### Requirement: Delivery 3 technical restrictions
Delivery 3 SHALL keep the compatible restrictions of previous deliveries (Java 21, Maven, executable JAR from `mvn package`) and SHALL use layered packages, the Builder pattern for invoices, Singleton for unique controllers, non-singleton repositories configured and injected at initialization, BCrypt as the only external runtime dependency, bounded generics with access interfaces for attractions, keep consumed passes, and perform group SpeedPass entry atomically.

#### Scenario: Only BCrypt at runtime
- **WHEN** the `pom.xml` dependencies are inspected
- **THEN** the only non-test dependency is `org.mindrot:jbcrypt`

#### Scenario: Command file in both modes
- **WHEN** `java -jar target/amusement-park.jar input_fase3.txt` and `java -jar target/amusement-park.jar --fly input_fase3.txt` are run
- **THEN** both process the file, and after the `--fly` run no data generated by it remains

### Requirement: Delivery 3 commit roadmap
In addition to the Delivery 1 and 2 commits, the Git history SHALL contain, in this order, `[F3-C01] Reorganize application into layered packages`, `[F3-C02] Add invoice generation with builder`, `[F3-C03] Add singleton controllers and dependency injection`, `[F3-C04] Add extended help generation`, `[F3-C05] Secure stored user passwords`, `[F3-C06] Add speed and special passes`, `[F3-C07] Add generic attraction access types`, `[F3-C08] Extend attraction access and pass consumption`, `[F3-C09] Extend delivery 3 persistence and UML` and `[F3-C10] Complete delivery 3 integration`.

#### Scenario: Roadmap commits present in order
- **WHEN** `git log --reverse --format=%s` is inspected
- **THEN** all 31 roadmap messages appear in order
