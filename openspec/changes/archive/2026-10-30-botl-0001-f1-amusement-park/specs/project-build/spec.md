# Spec Delta

## Purpose

Defines how the amusement-park application is built, tested and packaged: a Java 21 Maven project following the Maven Quickstart layout that produces an executable JAR.

## ADDED Requirements

### Requirement: Java 21 Maven Quickstart project
The project SHALL be a Maven project that compiles for Java 21 and retains the standard directory structure generated by `org.apache.maven.archetypes:maven-archetype-quickstart` (`src/main/java`, `src/test/java`, `pom.xml`). It SHALL use only the Java standard library at runtime.

#### Scenario: Clean project build
- **GIVEN** the project is checked out in an environment with a JDK capable of targeting Java 21
- **WHEN** `mvn test` runs
- **THEN** the project compiles and all its tests pass

#### Scenario: No runtime third-party dependencies
- **WHEN** the project's declared dependencies are inspected
- **THEN** any third-party dependency is limited to the `test` scope

### Requirement: Executable JAR
The build SHALL produce a JAR whose manifest declares the application entry point, so that `java -jar <jar>` starts the application without an IDE.

#### Scenario: Launch packaged application
- **GIVEN** the project has been packaged with `mvn package`
- **WHEN** the produced JAR is launched with `java -jar`
- **THEN** the application starts and enters its command-execution path
