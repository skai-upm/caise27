# Proposal

## Why

The amusement-park application has no code base yet. Before any domain functionality can be developed, a Java 21 Maven project must exist that compiles, runs its tests, and packages into an executable JAR. This is the first laboratory step of the project.

## What Changes

- Generate a Maven project from the `org.apache.maven.archetypes:maven-archetype-quickstart` archetype at the repository root, keeping its standard layout (`src/main/java`, `src/test/java`, `pom.xml`).
- Configure the build to compile with JDK 21 (`maven.compiler.release` = 21).
- Keep the archetype's executable main class (`App`) and its test class (`AppTest`).
- Configure the JAR manifest so `mvn package` produces an executable JAR whose `Main-Class` is the application main class.
- No application-domain functionality is added.

## Capabilities

### New Capabilities
- `project-build`: How the application is built, tested and packaged: Java 21, Maven, standard quickstart layout, test structure, and an executable JAR with a declared main class.

## Impact

- New files: `pom.xml`, `src/main/java/.../App.java`, `src/test/java/.../AppTest.java`.
- `.gitignore` already ignores `target/`.
- Build requires a JDK ≥ 21 and Maven 3.x; JUnit is the only (test-scoped) dependency, as generated by the archetype.
