## MODIFIED Requirements

### Requirement: Delete user
The command `USER DELETE;Correo;Contraseña` SHALL delete the user with that email only if it exists and the password matches the stored password, and SHALL then update the persistent file. Otherwise no user SHALL be deleted and an error message SHALL be reported. Deletion SHALL also be rejected while the user has any ticket (individual or generated by a group ticket) dated on or after the system date; tickets dated before it do not prevent deletion. A deleted user SHALL be removed from every group.

#### Scenario: Successful deletion
- **WHEN** user `ana@correo.com` with password `Clave1!` exists and `USER DELETE;ana@correo.com;Clave1!` is executed
- **THEN** the user is removed from memory and from the persistent file

#### Scenario: Unknown email or wrong password
- **WHEN** `USER DELETE` is executed with an email that does not exist or a password that does not match
- **THEN** no user is deleted and an error message is shown

#### Scenario: Current or future ticket blocks deletion
- **WHEN** `SYSTEM DATE;2026-10-01`, `TICKET CREATE;T001;ana@correo.com;2026-10-15` and `USER DELETE;ana@correo.com;Clave1!` are executed
- **THEN** the deletion is rejected

#### Scenario: Past ticket does not block deletion
- **WHEN** after the previous scenario `SYSTEM DATE;2026-10-16` and `USER DELETE;ana@correo.com;Clave1!` are executed
- **THEN** Ana is deleted and T001 is kept as a historical ticket

#### Scenario: Removed from groups
- **WHEN** Ana belongs to G01 without current or future tickets and is deleted
- **THEN** G01 no longer contains Ana
